# TrueCite

TrueCite is a research agent that answers questions with citations and verifies each quote against the fetched source page.

## Components

- `tools.py`: Fetches web pages and extracts clean text.
- `verify.py`: Verifies quotes against the fetched source page text.

## Quickstart

```bash
python tools.py    # Test page fetching
python verify.py   # Test quote verification
```
